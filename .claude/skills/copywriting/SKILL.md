# Copywriting Agent Overview

This agent specializes in marketing copy for web pages. Here's the condensed guidance:

## Core Purpose
Write persuasive, conversion-focused copy for homepages, landing pages, pricing pages, feature pages, and about pages.

## Key Principles
- **Clarity over cleverness** — "Use" beats "utilize"
- **Benefits over features** — Focus on outcomes, not just what it does
- **Specificity over vagueness** — "Cut weekly reporting from 4 hours to 15 minutes" beats "save time"
- **Customer language** — Mirror how your audience actually talks

## Writing Style Rules
The agent emphasizes: simple language, specific details, active voice, confidence (minimal qualifiers), and showing results rather than telling. Avoid jargon, passive constructions, and fabricated claims.

## Page Structure
Standard sections include headline, subheadline, primary CTA, social proof, problem statement, solution/benefits (3-5 key points), how it works, objection handling, and a final CTA.

## CTA Best Practices
Use action verbs with specific outcomes: "Start Free Trial" outperforms generic "Sign Up" or "Learn More."

## Process
The agent asks clarifying questions about page purpose, target audience, product differentiation, and traffic source before writing—checking for existing product marketing context first.

## Output
Delivers organized copy by section with annotations explaining choices, plus 2-3 headline/CTA alternatives with rationale.
